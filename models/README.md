# models/

Katalog na wagi modeli. Zawartość (poza tym plikiem) nie jest śledzona w Git.

- Modele o licencji permisywnej (Johnson: 4 style BSD-3, AdaIN: MIT) są
  dołączane do wydania w tym katalogu.
- Pozostałe modele pobiera `pastiche download <nazwa>` zgodnie z `models.json`
  (URL, SHA-256, licencja) w katalogu głównym repozytorium.
- Inny katalog: `--models-dir <ścieżka>` lub zmienna środowiskowa
  `PASTICHE_MODELS_DIR`.
